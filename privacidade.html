Política de Privacidade

Última atualização: 17/10/2026 (rev. 2)

1. Quem usa e quais dados

O Robô Mira do Pai é usado somente pelo criador do canal Mira do Pai. Ele não coleta dados de espectadores nem de outras pessoas. Os únicos dados tratados são do próprio criador:

  • as gravações de gameplay e o áudio do microfone do criador, para editar os vídeos;
  • os tokens de acesso às contas do canal no YouTube e no TikTok, concedidos pelo criador, para publicar;
  • as mensagens que o criador envia ao próprio bot no Telegram, para aprovar e ajustar vídeos.

2. Uso dos dados do YouTube e do TikTok

Com a autorização do criador, o aplicativo usa as APIs do YouTube e do TikTok apenas para enviar os vídeos do canal e definir título, descrição, hashtags e visibilidade. Ele não lê comentários, inscritos, mensagens nem dados de outras contas, e não usa os dados para publicidade.

O uso de informações recebidas das APIs do Google segue a Política de Dados do Usuário dos Serviços de API do Google, incluindo os requisitos de Uso Limitado.

3. Onde os dados ficam

Tudo fica no computador do criador. Os tokens de acesso ficam num arquivo local, fora de qualquer repositório de código. Nenhum dado é vendido. Serviços usados e o que cada um recebe: Telegram (o vídeo de prévia e as mensagens entre o criador e o próprio bot); Claude, da Anthropic (só a transcrição das falas do criador nos vídeos, para sugerir o texto de publicação); YouTube e TikTok (os vídeos publicados). A transcrição de áudio é feita no próprio computador.

4. Retenção e exclusão

Os arquivos ficam enquanto o criador quiser e podem ser apagados por ele a qualquer momento. Para revogar o acesso do aplicativo: myaccount.google.com/permissions (Google/YouTube) e configurações de segurança e apps do TikTok. Ao revogar, os tokens locais deixam de funcionar e o criador pode apagá-los do computador.

Privacy Policy

Last updated: October 17, 2026 (rev. 2)

1. Who uses it and what data

Robô Mira do Pai is used only by the creator of the Mira do Pai channel. It does not collect data from viewers or anyone else. The only data processed belongs to the creator:

  • the creator's gameplay recordings and microphone audio, to edit the videos;
  • access tokens to the channel's YouTube and TikTok accounts, granted by the creator, to publish;
  • messages the creator sends to their own Telegram bot, to approve and adjust videos.

2. Use of YouTube and TikTok data

With the creator's authorization, the application uses the YouTube and TikTok APIs only to upload the channel's videos and set title, description, hashtags and visibility. It does not read comments, subscribers, messages or other accounts' data, and does not use data for advertising.

Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

3. Where data is stored

Everything stays on the creator's computer. Access tokens are stored in a local file, outside any code repository. No data is sold. Services used and what each receives: Telegram (the preview video and messages between the creator and their own bot); Anthropic's Claude (only the transcript of the creator's speech in the videos, to suggest the post text); YouTube and TikTok (the published videos). Audio transcription runs locally.

4. Retention and deletion

Files are kept as long as the creator wants and can be deleted by the creator at any time. To revoke access: myaccount.google.com/permissions (Google/YouTube) and the TikTok app security settings. After revocation, local tokens stop working and the creator can delete them from the computer.
